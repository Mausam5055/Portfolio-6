The studio

We start with the site, not a style. How the sun moves across it, what the ground is made of, which views to hold and which to frame. The building follows from there.

Every project is led by one architect from first sketch to handover, so the idea that shaped the drawings is the one that gets built.

We work with local makers and materials wherever we can. It keeps buildings honest, and it keeps them easier to live with for decades.
